Every confidence interval straddles zero

At every horizon, both views: the block-bootstrap CI (which preserves the week-to-week dependence a 2-/3-week window creates) and the non-overlapping every-3rd-week sanity check (genuinely independent weeks, but only 44 of them) both include zero. Per HARNESS §10, this is not evidence Literal has negative edge, and it is not evidence it doesn't — 131 weeks of noisy, mostly single-digit-name weekly baskets is not enough to resolve a signal this size either way. Read the point estimates (all six are negative) as a direction worth watching, not a verdict.

Backtest replay, same caveat as §02/§03
