Per-trade score — §3.8 v1 shadow, not used to select or size

Every survivor table below now carries a Score column: edge_score × guardrail = candidate_score. This resolves §6 open decision #9 in favour of shipping a v1 now, from parameters already computed today, rather than waiting on §3.7 items 2–3 (window-offset split, days-since-flip) — which still don't exist and aren't in this score.

Edge score (0–100)§3.8.1
Identical formula/weights to build_trades()'s own confidence — RR, RSI-band centrality, sector RS, trend quality (ATR-based), volume ratio, liquidity. Same number for a Control trade and a T1 candidate, so the two are directly comparable.
Guardrail multiplier (0–1)§3.8.2
Risk-cap headroom, liquidity multiple, market-cap band position — discounts the edge score, never adds to it, per §3.8's gate-or-discount-never-blend rule. A name sitting right against the 15% cap or the ₹50k cr band edge gets discounted hard even with a strong edge score.

Still not live, still not weighted

Not used to select or size any trade in any arm — §3.8 is explicit that weights are unvalidated until B6's rank-IC test runs against enough graded weeks. Days-since-flip, window-offset identity, and per-ticker reversal frequency (§3.8.1's instrumentation-pending bucket) aren't in this v1; they still wait on §3.7 items 2–3.

None of the above changes what happens with real capital. These are the lines the response plan draws, restated so they travel with the data.

  • ×
    Loosen the RSI band or the 15% risk cap on this evidence.
  • ×
    Let T1/T2/T3 (including the score≥40 filtered sub-basket) touch real capital before it beats Control with a bootstrap CI that excludes zero.
  • ×
    Widen the universe or VStop sensitivity to chase trade count — that path is the V-series, not this one.
Open, unresolved
  • ✓
    Daily-bar priority — resolved this session (backfilled); still sharpens V3/V4 entry timing separately.
  • ✓
    §3.8 v1 score vs. wait for §3.7 items 2–3 — resolved this session, ship v1 now.
  • ?
    Extended history: pull 10+ years now, or keep the partly-spent window.
  • ?
    Regime gate V6 and shorting V7 — both still parked.
  • ?
    §3.8.2 guardrail architecture: full multiplicative discount implemented (headroom × liquidity × band position, each linearly ramped to a full-credit threshold) — thresholds themselves are v1 placeholders, not yet validated.
